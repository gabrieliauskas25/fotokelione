# Babylon.js animacijos – namų darbas

Kiekviena užduotis – atskiras `.js` failas Babylon Playground formatu (`createScene` funkcija).
Paleisti: atidaryti https://playground.babylonjs.com, ištrinti esamą kodą, įklijuoti failo turinį ir paspausti Run.

1. `1_grouping.js` – Grouping Animations: 2 grupės + GUI mygtukai Play/Pause/Stop.
2. `2_combining.js` – Combining Animations: 3 animacijos per `scene.beginDirectAnimation(box, [anim1, anim2, anim3], ...)`.
3. `3_sequencing.js` – Sequencing Animations: 5 performeriai, Sequence Timetable komentare.
4. `4_mixamo_character.js` – Mixamo veikėjas HVGirl.glb: W/S – eiti, A/D – suktis, B – šokti.
5. `5_animated_mesh.js` – Xbot.glb iš Babylon bibliotekos, animacijų mygtukai, greičio slankiklis, kodo paaiškinimas komentare.
