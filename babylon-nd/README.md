# Babylon.js animacijos – namų darbas

Kiekviena užduotis – atskiras HTML failas. Atidaryti naršyklėje (reikia interneto, nes Babylon.js kraunamas iš CDN).

1. `1_grouping.html` – Grouping Animations: 2 grupės (group1 – 3 animacijos vienam kubui, group2 – viena animacija 3 sferoms), Play/Pause/Stop mygtukai.
2. `2_combining.html` – Combining Animations: 3 animacijos (judėjimas, sukimasis, spalva) sujungtos per `scene.beginDirectAnimation(box, [anim1, anim2, anim3], ...)`.
3. `3_sequencing.html` – Sequencing Animations: 5 performeriai, eiliškumas pagal Sequence Timetable (lentelė kode komentare).
4. `4_mixamo_character.html` – Mixamo veikėjas (HVGirl.glb) valdomas klaviatūra: W/S – eiti, A/D – suktis, Shift – greičiau, B – šokti.
5. `5_animated_mesh.html` – mesh iš Babylon bibliotekos (Xbot.glb), animacijos perjungiamos mygtukais, greičio slankiklis; kodo paaiškinimas – komentare failo viršuje.
